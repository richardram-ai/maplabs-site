# maplab.co.nz

Simple one-page index of Richard Ram's community mapping projects. Static HTML, no build step.
Hosted on Cloudflare Pages; deploys on push to main. The whole site is noindex (`_headers` and the robots meta tag).

- `index.html` — the page
- `presentation/` — Community Mapping Framework deck
- `logo*.svg`, `favicon.svg` — maplab logo (Inter Tight 500, converted to outlines)
- `fonts/` — self-hosted Inter Tight and Atkinson Hyperlegible Mono (SIL Open Font Licence)
